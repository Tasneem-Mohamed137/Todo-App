# Todo App

A simple and interactive Todo List web application built using **HTML, CSS, JavaScript, and TypeScript**. The application provides an intuitive interface for managing daily tasks, tracking progress, and organizing todos.

## Features

* **Add Tasks:** Create new todos with a simple input field.
* **Complete Tasks:** Mark tasks as completed using checkboxes.
* **Edit Tasks:** Double-click a todo to edit its text. Press Enter to save or Escape to cancel.
* **Delete Tasks:** Remove individual tasks.
* **Filter Tasks:** View all, active, or completed tasks.
* **Clear Completed:** Remove all completed tasks at once.
* **Clear All:** Remove all tasks from the list.
* **Task Counter:** Keep track of the number of remaining active tasks.
* **Responsive Design:** Clean and simple interface that adapts to different screen sizes.

## Technologies Used

* **HTML5:** Provides the application structure.
* **CSS3:** Handles styling, layout, and responsive design.
* **JavaScript (ES6+):** Implements application functionality.
* **TypeScript:** Provides static typing and improves code maintainability.

## Getting Started

### Prerequisites

* A modern web browser.
* Visual Studio Code (recommended).
* TypeScript compiler.

### Installation

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Navigate to the project directory:

```bash
cd Todo-App
```

3. Compile the TypeScript file:

```bash
tsc
```

4. Open `index.html` in your browser using Live Server or another local web server.

## How to Use

1. Enter a task in the input field.
2. Click **Add** to create a todo.
3. Use the checkbox to mark a task as completed.
4. Double-click a task to edit it.
5. Use the filters to display all, active, or completed tasks.
6. Use the footer buttons to clear completed tasks or remove all tasks.

## TypeScript Configuration

The project uses the following TypeScript compiler settings:

* Target: ES2020
* Module: ES2020
* Strict Type Checking: Enabled
* DOM and ES2020 Libraries Included
